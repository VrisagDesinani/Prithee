# Prithee

Prithee is a console-based game based on Shakespeare's Sonnet 18.

The program prints part of the sonnet and replaces a randomly chosen word
with underscores. The user must guess the missing word.

The game continues until the user gets either three answers correct or
three answers incorrect.

## Running the Program

1. Open the project in IntelliJ.
2. Make sure Java 26 is selected as the project JDK.
3. Open `Main.java`.
4. Run the `main` method.
5. Enter guesses in the console when prompted.

## Testing

JUnit tests are located in:

`src/test/java/PritheeTest.java`

Tests can be run through IntelliJ or using Gradle.
